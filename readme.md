# Portafolio Personal de Juseth Porto
## Descripción
Este repositorio contiene mi portafolio web personal, donde muestro mis habilidades, proyectos y experiencia como desarrollador. El sitio está diseñado para presentar de manera profesional mi perfil a posibles empleadores, clientes y colaboradores.

## Vista Previa
El portafolio incluye secciones para:

- Información personal y profesional
- Mis habilidades técnicas
- Proyectos destacados
- Formulario de contacto
- Enlaces a redes sociales
## Tecnologías Utilizadas
- HTML5
- Imágenes optimizadas para web
## Estructura del Proyecto
```
├── images/
│   ├── juseth.jpg       # Foto de perfil
│   ├── men.jpg          # Imagen para proyectos
│   └── Chris-Hemsworth.webp # Imagen de prueba
├── index.html           # Página principal del portafolio
└── readme.md            # Este archivo
```
## Características
- Diseño responsive adaptable a diferentes dispositivos
- Navegación intuitiva con enlaces internos
- Secciones claramente definidas para facilitar la lectura
- Formulario de contacto funcional
- Enlaces a perfiles profesionales (GitHub, LinkedIn, Instagram)
## Instalación y Uso
1. Clona este repositorio:
   ```
   git clone https://github.com/Jusethporto/portfolio-riwi.git
   ```
2. Abre el archivo index.html en tu navegador web preferido
## Personalización
Puedes personalizar este portafolio modificando:

- El contenido en index.html para actualizar información personal y proyectos
- Las imágenes en la carpeta images/ para mostrar tus propias fotos y capturas de proyectos
- Añadir estilos CSS para mejorar la apariencia visual
